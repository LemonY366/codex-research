# 专利材料

`patents/` 存放基于论文研究成果整理的专利相关材料，例如技术交底书、权利要求草案、附图源文件、现有技术检索笔记和申请版本记录。这里的文档用于技术与写作准备，不替代专利代理人或法律顾问的正式意见。

## 建议结构

```text
patents/
├── README.md
├── draft_zh.md          # 中文技术交底书或专利草稿
├── claims_zh.md         # 权利要求草案
├── prior_art.md         # 现有技术与差异点记录
├── figures/             # 专利附图及可编辑源文件
└── versions/            # 提交前的版本快照
```

创建草稿时，应从 `RESEARCH.md`、已验证的实验运行和 `paper/draft_zh.md` 提取技术事实，但不要直接复制论文叙述。重点说明可实施的技术方案、必要技术特征、模块关系、输入输出和产生的技术效果。

## 工作规则

- 在 `draft_zh.md` 先完成技术交底；只有用户明确要求时才准备正式申请文件。
- 在 `prior_art.md` 记录检索来源、日期、相关性与关键差异，避免将新颖性或可专利性当作未经核实的事实。
- 权利要求应由实施方式支持；不得编造实验结果、技术效果或实施细节。
- 附图应保留可编辑源文件，并与权利要求中的术语和编号一致。
- 记录发明人贡献、公开日期、提交版本和保密限制；公开论文或演示前应先确认专利策略。

正式提交、权利要求范围、现有技术判断和地域策略应由具备资质的专利专业人士复核。
