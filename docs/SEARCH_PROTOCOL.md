# 阶段一搜索、真实性与资源记录协议

本文档是候选方向检索覆盖、来源质量、引用核验、冲突处理、搜索停止、阶段一资源计量、上下文压缩和文件维护的稳定规范。阶段一状态与确认仍遵循 `PHASE_ONE_PROTOCOL.md`，阶段切换遵循 `WORKFLOW_GATES.md`。阶段一不设置固定查询、页面、调用、费用、时间或存储上限。

## 每个候选方向的通用搜索协议

每个 `DIR-<nnn>` 必须单独规划和记录搜索，不能只围绕首个候选或单一关键词展开。至少覆盖：

1. 背景；
2. 现有方法；
3. baseline；
4. 研究空白；
5. 失败和负面结果；
6. 数据集与指标；
7. 许可与可行性；
8. 相似工作。

每个方向还必须具有中文和英文关键词扩展，并执行向后引用追踪、向前引用追踪或可说明的等价追踪。实际查询进入 `research/search_log.jsonl`，方向级覆盖和停止依据进入 `research/search_coverage.yaml`。查询记录应关联 `DIR`、`RQ` 和搜索类别；一次查询可以覆盖多个类别，但不能仅靠字段声明替代实际结果检查。

## 来源质量等级

| 等级 | 来源 | 默认用途 |
| --- | --- | --- |
| 1 | 原始论文、正式标准、官方原始数据 | 关键研究判断的首选直接证据 |
| 2 | 系统综述、权威技术报告 | 综合判断、方法分类和原始来源导航 |
| 3 | 官方文档、机构报告 | 实现、版本、政策、产品或机构事实 |
| 4 | 新闻、博客、行业分析 | 背景线索和补充说明 |
| 5 | 论坛、聚合页、未经核实内容 | 仅用于发现线索，不支持研究合同 |

关键研究判断优先使用一级或二级来源。三级来源可以支持其权威范围内的具体事实；四级和五级来源不能作为合同主张的唯一证据。二手来源必须通过 `primary_source_id` 追溯到已登记的原始出处。转载、镜像和内容聚合使用相同 `independence_group`，无论页面数量多少都只计为一个独立证据组。

## 可观察的搜索停止条件

不得声称“完全检索”“穷尽所有文献”或以模型主观感觉停止。每个候选方向只有在以下代理指标已记录时才可标记为 `已停止`：

- 连续批次的新增独立来源率呈下降趋势；
- 最新查询批次不再产生新方法类别；
- 关键研究问题均有来源覆盖；
- 已执行失败、反例和反证检索；
- 已覆盖计划中的语言、平台/数据库和时间范围；
- 未覆盖数据库、语言、时间段、付费或受限资料已明确披露；
- 停止理由说明是证据饱和代理或可行性阻断，而不是额度耗尽或宣称完全检索。

如果证据不足、来源冲突未解决或覆盖代理不满足，应保持 `进行中`、回到搜索，或明确停止并拒绝形成确定性结论。

## 引用支持检查

有 URL、DOI 或引用不代表主张已经验证。允许主张进入研究合同前必须检查：

- URL、DOI、标准号或其他定位符确实存在，并记录核验日期与方式；
- 页码、章节、表格、行号或锚点直接支持最小事实主张；
- 数字、单位、日期、版本、样本范围和统计口径与原文一致；
- 主张没有扩大到来源未覆盖的人群、场景、模型、时间或因果范围；
- 没有把相关性改写为因果关系；
- 模型推论明确标注为推论，不能伪装成来源结论。

这些检查记录在 `sources.yaml` 和 `claims.yaml`。验证器只能检查字段、关系和状态，不能代替打开原始来源进行语义核验。

## 冲突与不确定性

- 不删除不利来源、反例或失败结果。
- 相互冲突的证据保留在同一主张的来源集合或拆成可比较的最小主张。
- 冲突类型使用 `事实冲突`、`定义差异`、`版本差异`、`场景差异`、`多重差异` 或 `待判定`。
- `conflict_reason` 记录可能原因，`uncertainty_notes` 记录剩余未知。
- 冲突或证据不足时，主张保持不合格、未决或明确拒答；不得通过忽略反例获得确定性结论。
- `adverse_evidence_retained` 记录不利证据是否得到保留；模型自报置信度永远不是证据质量字段。

## 阶段一资源计量

累计使用量写入 `research/resources.yaml`，用于复现、审计和发现异常，不作为工作停止上限。每个当前快照至少记录：

- 头脑风暴输入、输出与合计 token；
- 阶段一累计输入、输出与合计 token；
- 搜索返回 token 或字符数及单位；
- 搜索页面和查询数量；
- 外部工具和 API 调用次数；
- 总耗时；
- 估算费用和币种；
- 阶段一证据文件字节数；
- 主张数量；
- 上下文压缩次数。

不能可靠获得的指标写为 `null`，并在 `unavailable_metrics` 中说明字段名和原因；不能用 0 伪装未知值，也不能把 token、字符、页面、文件字节和进程内存混称为“内存大小”。阶段一不要求 `max_*`、`stop_behavior` 或固定研究周期字段。

## 阶段一搜索停止行为

阶段一只在可观察证据饱和、用户结束调研、关键来源不可访问、许可或隐私风险、未获授权外部传输、付费操作尚未授权等情况下停止或暂停。不得用预设查询数、页面数、工具调用数、文件体积或研究周期代替搜索充分性判断。

付费检索、外部 API、受限访问和数据外发仍必须在实际发生前获得明确授权；这类授权控制是否允许某项动作，不构成阶段一默认资源配额。不得为了满足形式完整性虚构查询、来源或资源计数。

## 上下文压缩

1. 原始网页、论文和工具响应不整体进入活动上下文或 `RESEARCH.md`。
2. 先提取 `CLM` 最小主张、`SRC` 定位、支持程度和冲突，再撰写按 `RQ` 的原创摘要。
3. 删除或合并重复搜索结果时保留原查询、独立性组和来源 ID。
4. 压缩后的每项关键结论回查原始来源位置；压缩不能把推论升级为事实。
5. 用户授权、隐私、许可、停止条件、关键限制和阶段状态不得被压缩删除。
6. 已否决方向保留方向 ID、理由和决策 ID。
7. 压缩前后检查稳定 ID、数值、单位、版本、冲突、范围和未决问题一致；增加 `context_compactions` 计数。

## 文件体积控制

- `RESEARCH.md` 同时使用行数和字节数预警；超限时把已完成过程压缩为摘要和证据链接。
- 活动搜索日志达到 5,000 条或 2 MiB 后按 `research/archive/README.md` 轮转，不截断历史记录。
- 单来源抽取和摘要应保持最小必要；验证器保留防止全文、超长字段和敏感内容进入证据层的安全限制，但这些限制不是阶段一研究配额。
- 网页、论文和受限原文不得写入研究合同或可提交证据。
- 大型来源、附件和产物遵循许可证、隐私、Git 与目录提交边界。
- 证据量增长时优先压缩重复摘要并按日志轮转规则维护文件；保留查询、来源、主张、冲突、不利证据和稳定 ID，不因体积增长自动结束研究。
