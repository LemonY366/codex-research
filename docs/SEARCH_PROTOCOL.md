# 阶段一搜索与真实性协议

阶段一搜索服务于方向决策和研究设计，不以查询数量、页面数量或形式化覆盖为目标。非正式 IDEA 只做轻量侦察；正式入围方向才建立可追溯证据，最终方向必须完成足以支持创新性与可行性判断的正式验证。

## 决策驱动查询

每次查询前明确它可能改变的决定，例如保留、修订、合并、淘汰或选择方向。不会影响当前决定的查询不执行。

优先顺序：

1. 明确声称新的问题、机制、贡献或验证方式；
2. 扩展中英文、同义词和跨领域术语；
3. 先筛标题、摘要、DOI、作者、年份和综述；
4. 去重后只打开最接近的原始来源关键位置；
5. 提取最小主张和证据位置；
6. 后续使用来源 ID 和结构化摘要，不重复打开全文。

不得把“未搜索到”写成“没有已有工作”，不得因名称不同忽略语义等价工作。

## 轻量侦察

轻量侦察不要求 `DIR`、八类覆盖或证据饱和。它只回答：是否有明显重复、最低可行路径或硬阻断。结果只能支持 IDEA 的保留、修订或淘汰，不能直接支持正式创新性声明。

轻量侦察默认不打开长网页或论文全文；若某个原始来源会直接改变方向去留，可以读取其关键位置并登记来源。

## 正式验证范围

正式入围方向根据其创新性声称选择必要范围，至少检查：

- 最接近已有工作与主要 baseline；
- 当前问题、机制、贡献和验证逻辑的实质差异；
- 相似工作、失败、局限、负面结果和反证；
- 数据、指标、许可、隐私、访问和基本资源可行性；
- 中英文与关键同义词；
- 对核心来源的必要向前/向后引用追踪。

`search_coverage.yaml` 记录计划范围、已覆盖范围、未覆盖范围和停止依据。覆盖范围由当前创新性主张决定，不要求为已淘汰的非正式 IDEA 补齐固定类别。

## 来源与主张

每次正式查询在 `research/search_log.jsonl` 追加一个脱敏 `QRY-<nnn>`。正式使用的来源登记为 `SRC-<nnn>`，进入方向判断或合同的最小事实登记为 `CLM-<nnn>`，持久决策登记为 `DEC-<nnn>`。

关键判断优先使用原始论文、标准、官方数据、系统综述或权威报告。二手来源应追溯原始出处，同源转载不构成独立交叉验证。核验定位符、支持位置、数字、单位、日期、版本、范围、因果措辞和模型推论状态；保留冲突、不利证据和剩余未知。

## 停止条件

正式方向使用一种停止类型：

- `证据饱和`：最近批次的独立来源和方法类别增量下降，关键问题、最近工作、反证、引用追踪和计划范围已经覆盖；
- `可行性阻断`：有可回查来源证明许可、隐私、访问、资源或方法学条件无法满足，并披露未覆盖范围。

最终选定方向必须达到证据饱和；可行性阻断方向不得被选定。不得声称完全检索或穷尽所有文献。

## 上下文控制

- 不把网页、论文或工具响应全文放入 `RESEARCH.md` 或长期活动上下文。
- 先去重，再读取；先抽取最小主张，再撰写摘要。
- 同一来源默认只读取一次，后续通过 `SRC` 和 `CLM` 恢复。
- 工具返回只保留当前决定所需内容，避免完整结果列表、完整 diff 和无关日志。
- 压缩后回查关键来源位置，不把推论升级为事实。

付费、外发和受限访问在实际动作前按 `docs/PHASE_ONE_PROTOCOL.md` 单独授权。活动查询日志达到 5,000 条或 2 MiB 时按 `research/archive/README.md` 轮转；搜索按本协议的停止条件结束。
