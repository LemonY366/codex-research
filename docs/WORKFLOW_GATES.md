# 三阶段工作流门禁

本文档是调研与设计、实验与分析、论文写作三个阶段的进入、完成、停止、恢复和回退规则。Codex 在切换阶段前必须检查对应门禁，并将全局状态、长期决策和用户确认写入 `RESEARCH.md`；阶段二和阶段三任务分别写入 `experiments/TODO.md` 与 `paper/TODO.md`。门禁不得为了自动推进而绕过。

## 通用状态与原则

每个阶段使用以下状态：

- `未开始`：尚未进入该阶段。
- `进行中`：进入条件已满足，正在执行阶段任务。
- `已暂停`：命中停止条件，等待明确的恢复条件。
- `已完成`：完成条件均已满足或未完成项已获得用户明确的范围调整，并留有记录。

通用规则：

1. 进入条件未满足时，不得启动后一阶段的实质性工作。
2. 需要新的用户决策、授权、凭据、受限数据访问或范围扩展时，Codex 必须暂停并请求用户处理，不得自行假设。
3. 预算耗尽、负面结果或未达到目标指标不等于研究失真；若预定验证已完成且证据完整，可以如实结束阶段。
4. 任何停止都应在 `RESEARCH.md` 记录原因和恢复条件，并在受影响的阶段 TODO 中记录已完成和未完成工作；不得删除已生成的失败证据。
5. 研究问题、数据、指标、预算或范围发生实质变化时，先在 `RESEARCH.md` 记录决策，再回退到最早受影响的阶段重新检查门禁。

## 数据、隐私与外部传输门禁

数据访问和外部 API 调用必须同时满足凭据安全与数据安全：

- 在 `RESEARCH.md` 记录数据的来源、版本、许可证、数据分类、个人信息、内部或受限属性、公开限制与保留/删除要求。
- 在任何数据发送到外部 API 前，明确记录是否允许外发、允许范围、必要的脱敏方式和用户授权。未确认时默认不允许外发。
- 只传输完成实验所必需的最少数据；不在提示词、日志、截图、配置快照或运行元数据中保存密钥、完整环境变量、个人信息或受限样本。
- 外部 API 的输出也视为待检查数据；写入运行产物或论文前检查是否复现敏感内容。
- 存在许可证、隐私、保密性或外部服务条款疑问时，暂停相关工作并请用户确认；不将未确认的数据用于 API、实验或论文。

## 阶段一：调研与设计

### 进入条件

- 用户已提出基本研究方向，或明确授权 Codex 通过头脑风暴协助定义方向。
- Codex 已阅读 `RESEARCH.md`，并区分已确认信息与阶段一未决项。
- Codex 已按 `docs/SKILL_USAGE.md` 识别真实输入所需的 Skills；阶段名称本身不触发 Skill。
- 不需要用户在对话中提供密钥或其他真实凭据。

### 完成条件

- `RESEARCH.md` 已明确研究目标、研究问题、成功标准、主要指标、数据、baseline、必要的消融与稳健性验证。
- 数据来源、版本、许可证、隐私分类、外部传输边界和公开限制已确认。
- API/GPU 职责与数据流、所用模型、GPU 时间、API 调用和费用上限已确认；不使用的资源已标记为不适用。
- 计划使用的 Skills、依赖、外部传输、费用、内容保存位置和必要授权已登记；不使用时标记为不适用。
- 截止日期、范围外事项与阶段一交付物已明确。
- `experiments/TODO.md` 已生成可执行的阶段二任务，并在 `RESEARCH.md` 中记录用户对研究合同的确认或预先授权。

### 停止与恢复条件

任一必需完成项缺失，或存在数据权限、许可证、外发授权、预算、截止日期、范围或成功标准等必须由用户决定的问题时暂停。待用户补充并将决定记录到 `RESEARCH.md` 后，从未完成的门禁项恢复。

## 阶段二：实验与分析

### 进入条件

- 阶段一已完成，且 `RESEARCH.md` 中不存在会影响实验执行的关键未决项。
- 数据、模型、baseline、指标、API/GPU 分工、资源上限和外部数据传输授权已登记。
- 当前实验具有独立脚本计划、唯一实验 ID、明确输入输出、新的运行目录和可验证指标。
- 运行前预检已按 `AGENTS.md` 和 `experiments/scripts/README.md` 完成，只报告所需 API 变量“已配置”或“缺失”。
- 参与实验的 Skill 已满足依赖、许可、隐私、外发和预算门禁，且不会代替实验脚本或运行记录。

### 完成条件

- 预先确认的 baseline、主要实验、消融与稳健性验证已执行，或已记录用户确认的取消原因。
- 每个成功或失败运行都有不可变记录，且命令、配置、环境、日志、元数据、指标与失败原因符合 `experiments/runs/README.md`。
- 日志、输入摘要、模型输出和产物已完成密钥、个人信息和受限数据检查。
- 分析已覆盖负面结果、失败、异常值和局限，且所有实证结论可追溯到实验 ID。
- `experiments/TODO.md` 已更新实验任务状态，并已形成供阶段三使用的证据清单。

### 停止与恢复条件

遇到资源或凭据缺失、GPU 不可用或显存不足、API 重试或预算达到上限、数据损坏、指标实现错误、隐私或许可证风险、未授权的外部传输、研究范围变更或用户暂停时，立即停止相关工作。保留失败运行，不得把部分结果标记为成功。在资源、授权、数据或计划已修复并记录后，使用新的运行 ID 恢复；不覆盖原运行。

## 阶段三：论文写作

### 进入条件

- 阶段二已完成，或用户已明确确认对当前完整证据撰写负面、未完成或局限性报告。
- 每个计划写入的数值、表格、图像和实证结论均有实验 ID 与可核验运行记录。
- 参考文献可核实，数据、模型和外部 API 的许可证、引用、披露和公开限制已确认。
- 运行产物和预计写入内容已检查密钥、个人信息、内部信息和其他受限内容。
- 计划使用的 paper Skill 已回查原始来源；DOCX、PPTX、XLSX 或生成 PDF 等可选交付格式已获得用户明确要求。

### 完成条件

- `paper/draft_zh.md` 中本轮要求的章节已完成，结果、方法、局限性和负面结果表述与实际证据一致。
- 所有数值、表格和图像已标注数据来源、实验 ID，图像具有可复现生成脚本或可编辑源文件。
- 参考文献已核实，外部模型与本地模型的非敏感名称、用途和实验 ID 已披露。
- 所有 `TODO` 已完成、删除或明确说明保留原因，并完成隐私、凭据、许可证与公开边界检查。
- 用户已确认工作草稿达到本轮交付要求。正式 LaTeX 和专利材料不属于默认完成条件。

### 停止与恢复条件

存在缺少实验支撑的结论、与运行记录不一致的数值、无法核实的引用、不可复现图表、隐私或保密风险、未解决许可证/公开限制，或需要用户授权正式 LaTeX/专利工作时暂停。需要新证据时回退到阶段二；需要重新定义问题、指标、数据或范围时回退到阶段一。不得通过编造、推测或删除不利证据来解除停止。

## 阶段切换记录

每次进入、完成、暂停、恢复或回退时：

1. 更新 `RESEARCH.md` 的当前阶段、状态、门禁结果、停止原因、恢复条件和“阶段切换记录”。
2. 将影响研究合同的用户确认、范围变更或风险决策记录到 `RESEARCH.md` 的“当前决策”。
3. 阶段二更新 `experiments/TODO.md`，阶段三更新 `paper/TODO.md`；阶段任务文件不得复制运行日志或论文正文。
4. 保留既有实验运行和论文证据；新计划不得覆盖或倒改历史结果。
5. 只有门禁已通过且不需要新的用户授权时，Codex 才可按已确认的计划自主继续。
