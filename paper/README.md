# 论文目录

`paper/` 存放论文写作、引用、图像和最终排版相关的文件。论文中的实验性结论、数值与图表必须能够追溯到 `experiments/runs/` 中对应的运行记录和实验 ID。

## 核心文件

- `draft_zh.md`：**唯一的工作草稿**，用于研究、讨论、补充和修改论文内容。除非用户明确要求编辑其他论文文件，否则所有写作应先更新此文件。
- `main.tex`：正式论文文档，用于最终 LaTeX 排版、构建和投稿。不要在未获得用户明确指示的情况下直接改写它；应先在 `draft_zh.md` 完成并确认内容。
- `references.bib`：正式论文使用的 BibTeX 参考文献库。仅录入已核实的真实文献。
- `images/`：论文中引用的最终图像与图示；图像来源与处理规则见 `images/README.md`。

## 写作流程

1. 在 `draft_zh.md` 起草、修订和确认叙述。
2. 为每个实验结果标注对应实验 ID，并核对运行目录中的配置、日志和指标。
3. 核实引用来源后更新 `references.bib`。
4. 仅在用户要求生成、同步或修改正式 LaTeX 稿时，才将已确认内容写入 `main.tex`。

## 写作约束

- 不得编造实验设置、数值、图表、结论或参考文献。
- 无法核实的信息使用 `TODO` 标记。
- 不得为使论文叙述成立而修改实验脚本、运行结果或原始指标。
- 每个表格和图像都应说明其数据来源与实验 ID。

`paper/` 不用于存放临时实验日志、原始数据集或模型权重；这些内容应保留在各自的实验、数据集或模型目录中。
