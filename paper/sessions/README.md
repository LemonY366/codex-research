# 写作会话进度

`paper/sessions/<session-id>/` 保存阶段三实质性写作会话的可观察记录。每个会话由 `src/runtime/progress.py` 创建，至少包含 `status.json`、追加式 `events.jsonl` 和 `heartbeat.json`。

会话步骤应覆盖证据交接核对、提纲、逐节起草、引用核验、结果表/图核验、局限与负面结果检查及交付检查。只有存在可靠任务总数时才报告百分比；否则保持 `total: null`，使用当前步骤和检查点说明进度。

会话记录不得包含密钥、完整受限材料或未经核验的实验数字。完成后的会话记录用于解释写作过程和恢复位置，但不替代实验运行证据、正式引用或用户对草稿的确认。既有会话不得被新会话覆盖。
