# 调研摘要

本目录按研究问题保存精简调研摘要。文件名应包含对应研究问题 ID，例如 `RQ-001.md`；内容只综合 `../sources.yaml` 与 `../claims.yaml` 中可回查的证据，明确支持、反证、来源冲突和未决项，不保存网页或论文全文、长篇逐字摘录、搜索流水账、完整聊天记录或敏感材料。

## 压缩步骤

1. 原始来源不整体复制进摘要或活动上下文；先从原文提取 `CLM`、`SRC`、证据位置、数字/版本、范围和冲突。
2. 按 `independence_group` 合并重复转载的叙述，但保留全部来源 ID 和查询记录。
3. 每个摘要结论引用可回查的 `CLM`；压缩后重新打开原始位置核对关键结论。
4. 用户授权、许可/隐私边界、阶段二资源方案、付费边界、停止条件、关键限制和未决问题不得删除或弱化。
5. 已否决方向保留 `DIR`、否决理由和 `DEC`；不把旧方案重新包装成未决候选。
6. 压缩前后比较稳定 ID、数字、单位、日期、版本、适用范围、冲突和不利证据；发现变化时停止并恢复到未压缩证据核对。
7. 完成一次上下文或文件摘要压缩后，在当前 `resources.yaml` 快照增加 `context_compactions`，并更新实际文件字节数。

单份摘要不得超过当前 `max_summary_chars`。超限时按研究问题拆分或进一步去重，不通过删除限制、反例、冲突或证据链接缩短。

阶段一完成时删除重复和临时摘要，保留仍支撑当前研究合同、阶段二任务或后续写作的摘要。任何压缩都不得改变主张含义、隐藏不利证据或破坏稳定 ID 引用。
